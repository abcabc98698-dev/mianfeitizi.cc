# 内容蓝图

<ArticleMeta reading="6 分钟" note="选题状态为规划，不代表页面已经发布。" />

这张蓝图把 8 个一级专题拆成 64 个搜索意图分类与 128 个内容集群。每个集群规划 6 到 8 个可以独立回答问题的长尾选题。它按写作与核验队列组织，关键词只作为选题线索。

## 怎么读这张图

先按专题筛选，再按问题筛选。一个题目只有同时满足“有独立搜索价值”“不与同集群题目争夺同一意图”“可以用公开证据回答”三个条件，才会进入写作队列。没有证据的题目留在规划区，不生成空页面。

<PlanExplorer />

## 发布规则

规划中的题目不会生成可点击链接，也不会被提交到 sitemap。只有当一篇文章完成事实核验、独立写作、内链配置和结构化数据检查后，才会进入正式导航与站点地图。这样做会牺牲页面数量，但能避免把重复内容当成规模。
